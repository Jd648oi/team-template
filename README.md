# CP3405 TR3 2026 — Team Repo Template

Copy this structure into your own team repo (or copy these files into the matching folders if your repo already exists). One folder per role, one file per role, one report per sprint week — this is the structure every team is expected to follow starting this week, per the Blackboard announcement.

```
README.md
evidence/
  R1/   DoD.md
  R2/   almanac-macro.md
  R3/   technical.md
  R4/   data-calibration.md
  R5/   human-score.md
  R6/   llm-github-ui.md
reports/
  vW2.md   (this week — add vW3.md, vW4.md, ... as sprints continue)
```

Each `evidence/R*/` file is a fill-in-the-blank template matching that role's slide in the official Sprint Presentation Template — filling in the `.md` file and filling in your slide should use the same words. If something genuinely doesn't apply yet this sprint (e.g. no predictions exist before the pipeline goes live), say so explicitly in the file rather than leaving it blank or inventing content.
